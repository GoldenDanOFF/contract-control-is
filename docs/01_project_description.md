# 1. Описание проекта

## Наименование

Информационная система автоматизации контроля исполнения договоров.

## Область применения

Система предназначена для автоматизации процессов учёта, мониторинга и контроля исполнения договорных обязательств в организации. Область применения охватывает юридические отделы, договорные подразделения, а также руководителей, ответственных за контроль сроков выполнения обязательств.

## Проблема

В условиях значительного объёма договорной деятельности ручной контроль исполнения договоров сопряжён со следующими рисками:

- несвоевременное выявление приближающихся и истёкших сроков исполнения;
- потеря документов и актуальной информации о статусах договоров;
- отсутствие прозрачности ответственности за конкретные договоры;
- невозможность оперативного формирования отчётности по договорной деятельности;
- дублирование информации при использовании нескольких электронных таблиц.

## Цель проекта

Разработка информационной системы, обеспечивающей централизованное хранение сведений о договорах, автоматический контроль сроков исполнения и оперативное информирование ответственных сотрудников о состоянии договорных обязательств.

## Ожидаемый результат

- Единый реестр договоров с возможностью фильтрации по статусам.
- Автоматическая подсветка просроченных договоров.
- Удобный интерфейс для добавления и просмотра договоров.
- Демонстрационный прототип, иллюстрирующий основные функции системы.

## Пользователи системы

- Администратор системы
- Руководитель
- Юрист
- Ответственный исполнитель
- Наблюдатель
