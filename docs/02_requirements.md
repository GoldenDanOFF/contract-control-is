# 2. Требования к системе

## Функциональные требования

| № | Требование | Приоритет |
|---|-----------|-----------|
| FR-01 | Отображение реестра договоров в табличном виде | Высокий |
| FR-02 | Хранение атрибутов договора: номер, контрагент, дата заключения, срок исполнения, ответственный, статус | Высокий |
| FR-03 | Поддержка статусов: новый, в работе, на согласовании, исполнен, просрочен | Высокий |
| FR-04 | Фильтрация договоров по статусу | Высокий |
| FR-05 | Автоматическая подсветка просроченных договоров | Высокий |
| FR-06 | Форма добавления нового договора с валидацией полей | Средний |
| FR-07 | Отображение статистики: всего, в работе, просрочено, исполнено | Средний |
| FR-08 | Демонстрационные данные для проверки работоспособности | Средний |

## Нефункциональные требования

| № | Требование | Описание |
|---|-----------|----------|
| NFR-01 | Кроссбраузерность | Поддержка Chrome, Firefox, Edge (последние 2 версии) |
| NFR-02 | Адаптивность | Корректное отображение на экранах от 320px |
| NFR-03 | Производительность | Отрисовка таблицы до 100 записей без задержек |
| NFR-04 | Простота развёртывания | Запуск без серверного ПО — открытие HTML-файла в браузере |
| NFR-05 | Удобство использования | Интуитивный интерфейс, не требующий обучения |

## Ограничения

- Прототип не предусматривает серверную часть и базу данных.
- Данные хранятся в оперативной памяти браузера и не сохраняются между сеансами.
- Аутентификация и авторизация пользователей не реализованы в прототипе.
