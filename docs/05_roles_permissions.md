# 5. Роли пользователей и права доступа

## Категории пользователей ИС

| Роль | Права доступа |
|------|---------------|
| **Администратор системы** | Управление пользователями; настройка справочников; полный доступ ко всем договорам |
| **Руководитель** | Просмотр всех договоров; контроль сроков; формирование отчётов; изменение статусов |
| **Юрист** | Создание и редактирование карточек договоров; контроль согласования; прикрепление комментариев |
| **Ответственный исполнитель** | Просмотр назначенных договоров; изменение статуса исполнения; добавление комментариев |
| **Наблюдатель** | Только просмотр договоров и отчётов |

## Соответствие ролей GitHub

| Роль GitHub | Уровень доступа | Аналог в ИС |
|------------|----------------|--------------|
| Admin | Полный доступ к репозиторию | Администратор системы |
| Maintain | Управление репозиторием без опасных действий | Руководитель |
| Write | Чтение и запись кода | Юрист / Разработчик |
| Triage | Управление Issues и Pull Requests | Тестировщик |
| Read | Только чтение | Наблюдатель / Заказчик |
