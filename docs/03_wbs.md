# 3. Иерархическая структура работ (ИСР)

## Модель жизненного цикла

Для проекта выбрана **каскадная (водопадная) модель** жизненного цикла ИС с элементами итеративного подхода. Модель предполагает последовательное выполнение этапов: инициация → анализ → проектирование → разработка → тестирование → внедрение → сопровождение.

## Связь ИСР с ветками Git

Каждый этап жизненного цикла ИС отражён в соответствующей ветке Git-репозитория. Такой подход обеспечивает:

- **трассируемость**: возможность отслеживать, какие изменения относятся к каждому этапу;
- **изоляцию**: разработка на каждом этапе ведётся в отдельной ветке, не затрагивая стабильную версию;
- **контроль качества**: слияние в основную ветку происходит только после проверки.
