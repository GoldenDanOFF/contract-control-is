# Информационная система автоматизации контроля исполнения договоров

Данный проект представляет собой веб-прототип системы контроля договоров. 

## Возможности
- Ведение реестра договоров.
- Отслеживание статусов.
- Фильтрация по статусу (в работе, на согласовании, исполнен, просрочен).
- Подсветка просроченных договоров.

## Запуск
Для работы с проектом достаточно открыть файл `src/index.html` в любом современном браузере.

## Клонирование репозитория

git clone https://github.com/GoldenDanOFF/contract-control-is.git
